# RIIP：时间线按压策略，2026-11-25

## 本批范围

基线为主线 `93ff60c1420850c6db7f3248d234faee9cc655fa`。本批迁移编曲区和钢琴卷帘两个真实 `horizontal_timeline_bar` 入口中的按压策略，复用已有 `ContinuousControl`，不新增编译单元。Adwaita 外观及“点击槽位居中跳转、随后继续拖动”的默认体验保持一致。

基线已经消费主总线 insert bypass、布尔命令按钮和 checked menu 的源选择值；这些只是本轮复核和清单纠正，不重复算成新增实现。

## 作者源码与宿主职责

| 职责 | 所有者 |
|---|---|
| thumb 命中、槽位目标、像素与 tick 换算 | `ui_controls.rs` 的 Timeline 几何 closure |
| 是否立即跳转、armed/dragging、固定拖动起点 | `continuous-control.proto.ts` 的 `beginTrack` 与 `trackPress` |
| 三像素阈值、普通/Shift 候选选择、最终采样与提议 | 既有 ContinuousControl source 路径 |
| preview echo、策略/authority 变更取消、生命周期与重入 | ContinuousControl source；`trackPress` 参与同一策略快照 |
| 原生输入、窗口边界与捕获代际 | `proto_scalar.rs` 和 `OwnedPointerCapture` |
| 接受/拒绝源事件、viewport 写入、文档 authority | 现有 Editor callback 与 target 校验 |
| 绘图与布局、非线性 dB 和音乐参数单位 | 现有原生宿主 |

`beginTrack(candidate, thumbHit, resetModifier, double)` 接受物理命中与几何事实。源码默认 `trackPress = "jump"`：thumb 按下进入 armed，槽位按下选择居中候选并立即预览。`trackPress = "drag"` 时相同槽位事实只开始相对拖动。按压策略不是从 native `jump` 布尔值重建出来的。

`initialValue` 保存按下时接受的值，用于回退；独立的 `dragOrigin` 保存源码选定的拖动起点。槽位预览、host echo 和 repaint 不会重新选择起点。适配层在活动 track 输入中读取这个 source state，再做位移单位换算。

既有非 track 的 `begin` 接口与 numeric scrub 的 steps 行为保留。该批两个 Timeline 的 track geometry hook 始终存在；若未来允许同一 mount 在活动手势中切换输入类型，必须先取消旧 lease。

## 回归入口

[source tests](tools/test/continuous-control.test.mjs) 覆盖两种按压策略、thumb/槽位、范围夹取、没有 Move 的终端 sample、预览 echo、取消、提交后下一次拖动、策略/revision/disabled 变更、非法事实、卸载及同步重入。还保留旧 begin/reset/edit 的行为断言。

[native tests](../crates/verdant-app/src/ui_controls_timeline_tests.rs) 通过真实 `PlatformInput` 进入生产控件，不直接调用 source 的 begin/finish：

- 在同一槽位坐标只切换 source policy，验证起点和 MouseUp 后的实际 viewport 都跟随源码决定。
- 两个入口分别检查 thumb 阈值、预览重绘、仅松手时出现的 Shift、终端坐标和迟到 release；阻断普通 MouseUp bubble 后仍完成采样。
- 使用真实 Editor root 与应用快捷键，验证 Escape 回退、下一次 Escape 恢复原选择行为，并保护替换后的 capture generation。
- disabled 同步取消；真实项目 revision 和 document generation 退役后，旧 contact 的提交与回退都不能覆盖新的外部 viewport。
- 检查另一个 viewport、项目 revision、source 可访问值和捕获释放。

## 仍保留的边界

绝对标量的普通/fine 几何候选仍由宿主提供，尤其 fader 的非线性 dB、整数精度与 splitter 的 f32 回传不能简单统一。本批没有扩大到这些控件的数值映射。

音频导出是否改成模态草稿表单仍是产品决定；现有菜单已经使用 Proto。Vendored Input 的源码 revision 与 compiler pin 分开记录，本批只纠正其说明，不变更 Input 实现。
