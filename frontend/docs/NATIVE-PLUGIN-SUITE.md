# Verdant 内置插件与默认原生界面

本套件提供 **12 个音频效果器、2 个音符乐器**，覆盖 FabFilter 当前 14 个产品家族所对应的处理类别。效果器在独立的 `verdant-plughost` 进程处理音频，原生编辑器由 Verdant 桌面绘制；两个乐器使用播放与导出共用的音符合成路径。无需安装外部插件即可使用这些内置设备。

这里记录本仓库已经实现的控件、音频行为与验收范围。它们是 Verdant 的独立实现；产品类别覆盖不表示与 FabFilter 的专有算法、全部功能、预设格式或声音逐样本等价。FabFilter 产品名仅用于说明功能参照。产品范围按 2026-11-21 的[官方目录](https://www.fabfilter.com/products)核对。

## 入口、外观与窗口

在轨道的设备面板中选择“添加效果器”，或从混音器的轨道／主总线插入位添加设备。内置效果器加载完成后默认打开自己的原生窗口；再次选择“打开原生插件窗口”会激活该实例已有的窗口。乐器轨及其乐器选择器支持 Verdant Synth 和 Verdant One，并可打开独立原生乐器窗口。

设备链中的卡片和独立窗口共用同一个编辑器。轨道插入与主总线插入也共用参数写入、工程历史和状态保存路径。独立效果器窗口的“参数列表”在同一窗口内切换到全部参数的通用视图，“图形界面”可切换回来，无需跳转混音器。外部 CLAP、VST3、AU 插件在报告支持编辑器时打开它自己的宿主窗口，没有该能力时使用参数列表；内置编辑器不依赖外部插件的 `has_editor` 标志。

界面延续 Verdant 的 Adwaita 风格：统一浅色／深色主题、标题栏、圆角卡片、分段选择、可读的文字与单位、清楚的焦点和按下状态。字体优先使用 Adwaita Sans／Cantarell。频段颜色用于区分图中的对象，控件不使用 FabFilter 的商标图片或截图。界面由 GPUI 原生绘制，并非 GTK/libadwaita 控件，也不声明通过 GNOME 视觉一致性认证。

窗口随工程、当前文档世代和设备实例绑定。插入重排后仍跟随原实例；移除、替换、切换工程或重新打开同一个工程后关闭过期窗口。文档世代保证重新打开时即使工程 ID、轨道 ID 和插件 ID 相同，旧窗口及乐器手势仍然失效。没有唯一历史实例 ID 的旧工程使用当前 live key，避免同槽新插件收到旧窗口的修改。关闭窗口、失去窗口焦点或取消拖动会释放指针捕获并丢弃尚未提交的预览。

实现入口：[设备编辑器](../crates/verdant-app/src/devices.rs)、[套件控件](../crates/verdant-app/src/devices/suite.rs)、[原生窗口](../crates/verdant-app/src/plugin_editor.rs)、[窗口分派与参数事务](../crates/verdant-app/src/plugin_ui.rs)、[主题](../crates/verdant-app/src/theme.rs)。

## 通用操作

| 操作 | 行为 |
|---|---|
| 拖动旋钮或图中节点 | 先显示本地预览，释放时提交一次修改，成为一个撤销步骤；未越过拖动阈值的点击不会改变数值。 |
| 按住 Shift 拖动 | 使用更小的变化量微调；宽范围正值参数按对数尺度调节。 |
| Alt 点击、双击控件 | 恢复该控件的原生默认值。EQ 空白图区的双击另用于新增／启用频段。 |
| 点击数值或使用精确输入菜单 | 打开带单位的输入窗；Enter 应用，Esc 取消。支持 `1.25 kHz`、`300 ms`、`0.3 s`、`-6 dB`、`50 %` 等与参数单位相符的输入。 |
| 控件获得焦点后用方向键／加减按钮 | 按参数步长调节；连续参数可用 Shift 微调。枚举参数遵守其原生离散步长。 |
| 撤销／重做 | 使用工程历史；独立窗口支持 Ctrl/Cmd+Z 与 Shift+Ctrl/Cmd+Z。 |
| 旁通 | 在设备卡片、插入菜单或原生窗口中切换。参数仍保留在工程中。 |
| 参数组 A／B 与 A→B、B→A | 保存并切换当前实例的参数快照，或将当前参数复制到另一组；宿主确认整次写入后才更新活动组标签。 |
| 预设、初始化、重置 | 预设先恢复该设备默认值，再应用预设覆盖项；重置恢复所有已报告默认值的参数。 |

精确输入会拒绝非有限值、超界值、错误单位和已经失效的设备目标。输入窗打开后若工程版本或设备身份已经改变，需要重新打开输入窗；不会把旧值写入后来占据同一插入位的插件。参数事务等待宿主确认，并将确认后的状态存入工程。

A/B 是当前运行实例的编辑工作区；未活动的比较组不是工程文件中的第二份插件状态，关闭工程或重建实例后不保证保留。A/B 比较的是 DSP 参数，不包括旁通、侧链来源或窗口位置。当前预设是内置起始设置，不包含用户预设文件管理、FabFilter 预设导入或加载预设时锁定干湿比的功能。

效果器预设包含人声清晰、动态去浑浊、柔和人声、总线黏合、并行冲击、柔和降噪、鼓门、自然齿音、峰值保护、房间／大厅、短拍／乒乓／长回声、多段控制、滤波扫频等。Synth 提供铺底、拨弦、贝斯、主音、电钢、四振荡器弦乐和噪声打击；One 提供单振荡器贝斯、脉冲主音和柔和长音。两个乐器的独立原生窗口直接提供各自的出厂预设选择器。所有预设通过同一参数／状态通道实际改变声音。

### 实际信号与处理模型

12 个效果器的“信号分析”区域显示宿主实际处理的输入／输出，可切换频谱和波形，并分别显示左右声道的采样峰值与未加权 RMS。没有处理过音频时显示“等待音频”；测量样本停止更新超过一秒后标为“上次音频”。没有用持续运行的动画模拟正在播放的音频。

电平与频谱使用最多 2,048 帧的近期窗口，在 48 kHz 下约 42.7 ms；频谱采用 Hann 窗并平均两声道的功率，避免反相信号在显示中抵消。波形按每 64 帧的立体声极值保留最多 128 个点，最多约 170.7 ms，最后未填满的区间也按实际长度显示。信号获取、校验和频谱计算在控制／后台路径完成，绘制只读取有界缓存。

这一分析区与 EQ 频响、动态传输曲线、混响 RT60 模型、静态延迟抽头等图分开表达：前者来自样本，后者来自当前参数与 DSP 模型。现有计量不提供内部增益衰减历史、true peak、LUFS、长时最大值或响度标准认证；两个乐器没有独立的这一宿主计量面板。实现见[测量数据](../crates/verdant-plugins/src/telemetry.rs)和[信号显示](../crates/verdant-app/src/devices/signal.rs)。

## 逐设备控件与图形

### EQ

图中的横轴是频率，纵轴是增益。拖动节点改变频率与可适用的增益；关闭的选中频段以空心节点显示，拖动会启用它。双击空白区域启用第一个关闭的频段。右键节点或形状菜单选择峰值、低架、低切、高架、高切、陷波、带通、倾斜、全通；低切和高切支持 12／24／36／48 dB/oct。24 个频段标签可独立选择。

每段都有启用、频率、增益、Q、形状、斜率和立体声位置参数。增益只对峰值／架式／倾斜形状生效，斜率只对低切／高切生效；声道位置支持 Stereo、Left、Right、Mid、Side。动态区提供启用、最大正／负增益变化、阈值、启动和释放，作用于有增益的形状。外部侧链可驱动每段检测；单段独听播放该频段对应的带通检测区域。全局提供输出和自动增益补偿。

实线频响由音频路径使用的滤波系数计算；动态虚线是所设最大变化边界，不表示当前实时增益衰减。全通改变相位，幅度图保持平坦。自动增益根据静态频响估计补偿，不是对音频节目的响度匹配。

### Compressor

主要控件为阈值、比率、软拐点、最大压缩范围、启动、保持、释放、前视、补偿增益和干湿比。风格为干净、平滑、冲击、人声、总线、光学、向上、泵动；不同风格实际改变检测／增益计算或时间行为。自动释放响应当前增益变化，自动补偿按静态参考电平估计。

检测区包含峰值／RMS、侧链高通／低通、侧链监听、立体声联动和 Stereo／Mid／Side 处理选择。输入／输出增益独立可调。染色区提供关闭、电子管、二极管、明亮，配合驱动和压缩前／后位置。干声支路跟随前视延迟；染色作用于湿声处理路径。

传输曲线使用同一风格增益函数，并包含输入、补偿、干湿比和输出设置；它是静态电平关系，不表示启动／保持／释放的实时轨迹，也不包括染色产生的全部谐波。

### Gate

提供经典、干净、人声、吉他、向上、闪避 6 种风格。控件包括阈值、扩展比、最大范围、软拐点、迟滞、启动、保持、释放、前视、干湿比和输出。迟滞为开门与关门提供不同边界，保持避免刚过阈值就立即关闭。向上风格提升高于阈值的部分；闪避风格在输入超过阈值时降低增益。

检测区提供侧链高通／低通、监听、立体声联动以及 Stereo／Mid／Side 选择。图中阈值可拖动，静态传输曲线与当前风格一致。

### De-esser

提供阈值、最大衰减、检测起始频率、检测上限、启动、释放、前视、干湿比、立体声联动和声道选择。分频模式只降低高频支路；全带模式降低完整信号。人声检测根据高频与总能量比例调整触发程度，全能模式直接使用检测频带。可选择其他轨道作侧链并监听检测信号。

分频器采用 IIR Linkwitz–Riley 结构；它不是线性相位模式。干湿比为零时仍保留所设前视延迟，干声不会经过分频器重组。

### Limiter

提供输入增益、输出上限、前视、启动平滑、释放、立体声联动和透明／平滑／冲击／安全 4 种风格。可启用直流滤除、按输入增益反向补偿的比较模式，以及“监听限制差分”。外部侧链可增加所需衰减；主信号自身峰值仍参与保护。

限制器约束的是输出 PCM 的**采样峰值**。没有过采样重建峰值检测、ISP／true-peak 保证、LUFS／响度门限测量、抖动或噪声整形。等响比较只是反向补偿输入增益，不表示标准化响度匹配；差分监听是限制处理的差值信号。

### Reverb

基础控件包括预延迟、衰减时间、尺寸、阻尼、扩散、宽度、调制和干湿比。现代、复古、板式三种风格改变延迟网络、扩散／调制或量化特征。距离改变进入混响的延时与电平，厚度改变输入饱和与扩散。

衰减区提供全局衰减倍率、低频／高频衰减倍率与两处分界频率。后置 EQ 提供低切、高切、低架增益、高架增益、中频频率／增益／Q。冻结停止新信号进入混响池并保留池内反馈；闪避根据输入或外部侧链降低湿声；自动门限与保持时间截短尾音。

衰减图由反馈滤波模型估计频率相关 RT60，冻结时显示无限衰减语义；后置 EQ 图使用实际五节滤波器系数。RT60 是模型读数，不是对房间或音频进行测量得到的脉冲响应。这里没有任意节点 Decay Rate EQ／Post EQ、IR 拟合导入或卷积混响。

### Delay

主控件包括自由时间、左右时间偏移、反馈、交叉反馈、乒乓、宽度、干湿比、驱动和反馈高／低切。节拍选择包括自由时间以及 1/64、1/32、1/16、1/8、1/4、1/2、1 小节、2 小节；参考 BPM 参数用于没有宿主速度信息时的回退。已接入的宿主速度支持 20–1,000 BPM，参考参数保留原有 20–300 BPM 范围。启用节拍同步时，低于 20 BPM 的工程速度须由宿主明确拒绝，不会静默改成 20 BPM。宿主速度通过独立的传输信息进入 DSP，不通过反复修改保存的 BPM 参数模拟同步。

节拍事件按每一级的上游实际延迟对齐，并在稳定循环播放中按循环范围回绕。跳转不清空已有插件、反馈和桥接缓冲；跳转后的残留音频仍受原有缓冲历史及效果尾音影响，不能据此承诺无瞬态的即时切换。

主抽头有启用、电平和声像。额外 15 个抽头各有启用、相对于基准延迟的时间百分比、电平和声像；图中可以选择并拖动抽头。左右偏移会分别改变两个声道的读出时间，声像改变两声道的音量。

声音处理还包括 LFO 速率／时间深度、扩散、Lo-fi、正负动态量、反馈移调、镜像移调、冻结和闪避。移调在反馈路径中使用双窗读出，冻结保持现有循环并停止新信号进入。抽头图显示设定的静态时间／电平／声像，不把反馈、调制或实际声音画成未经测量的活动回声。

### Saturation

全局提供风格、驱动、音色、干湿比、输出、频段数、5 个分频点、驱动 LFO 速率／深度、反馈量／频率、动态量、去直流以及 L/R 或 M/S 处理。8 种形状为磁带、电子管、软削波、硬削波、折返、整流、变压器、位深压缩。

每个频段提供启用、额外驱动、风格、音色、干湿比、电平、声像、动态量、独听和静音。频段电平和声像作用于该段干湿混合后的结果；关闭频段处理时恢复该频段的干声，静音仍可将该段排除。分段风格可继承全局或指定 8 种形状中的一种。频段图拖动分频点和当前段驱动；传输图显示当前静态失真形状及干湿关系。全局输出调节效果路径；最外层干声保持原电平，因此全局干湿比为零时仍与输入一致。

互补低通／残差分频保证中性设置可重组干声。动态量与反馈、调制实际参与 DSP；静态传输图不能表示这些带历史的处理。当前没有过采样、线性相位分频、完整放大器／箱体模型或任意调制矩阵。

### Multiband

全局提供 1–6 个频段、5 个分频点、干湿比、输出和侧链监听。每段提供启用、阈值、正负动态范围、比率、启动、释放、软拐点、增益、独听和压缩／扩展模式。正负范围与压缩／扩展组合得到向上／向下处理；外部侧链分别经过检测分频，检测音频不混入主输出。

图显示每个实际互补分频器的静态幅频响应，节点可调整分频点。分频点使用不重叠的取值区间维持有序，频段是相邻连续区域；不支持任意悬空频段、任意重叠或每段独立的外部检测频带。该分频实现为一阶低通／残差结构，不是 Pro-MB 的 Dynamic Phase、Linear Phase 或其专有 Minimum Phase 实现。

### Filter、Dual Filter 与 Micro Filter

Filter 有 4 个、Dual Filter 有 2 个滤波单元，每个单元提供启用、截止频率、共振、低通／高通／带通／陷波、12／24／36／48 dB/oct 斜率和驱动。全局提供串联／并联、干湿比、输出、LFO 速率／深度、包络深度／启动／释放。所有启用单元共享 LFO 和包络调制源；包络可使用轨道侧链。

Micro Filter 提供截止频率、共振、低通／高通、驱动、包络深度／启动／释放、干湿比和输出。三个设备均可拖动截止频率节点。图使用音频路径同一滤波系数，按未调制的小信号条件绘制；非线性驱动和实时调制的声音超出该静态图的表达范围。

### Synth 与 One

两个乐器的音量包络均可通过起音、衰减／延音、释音图形节点编辑。共同控制包括振荡器波形、ADSR、滤波截止／共振／形状／包络量、脉宽、驱动、噪声、LFO 速率／音高深度／滤波深度、复音限制、滑音、键盘跟踪、力度响应和音量。波形为锯齿、方波、三角、正弦。

Synth 另有振荡器 2–4 的波形、半音音程和混合量，双振荡器失谐、立体声宽度、齐奏数量／失谐，以及第二滤波器开关、截止、共振、形状和串并联。最多 64 个音符声部、每音符最多 8 路齐奏；超过复音上限时旧重叠音符经短淡出让位。

One 只显示单振荡器适用的 20 个参数，最多 10 复音。其状态加载会忽略第二至第四振荡器等隐藏参数，不能通过旧状态意外开启多振荡器。它没有 Synth 的齐奏、第二滤波器或立体声宽度控件。

播放和导出从相同工程音符与参数合成。当前不是面向实时 MIDI 输入的外部合成器宿主；没有 Twin 3 的完整四滤波器结构、内建六效果区、琶音器、MPE、任意拖放调制矩阵或商业预设兼容。

## 侧链、状态与自动化

轨道侧链选择另一轨道的**插入前**信号。“无”表示检测当前输入；不允许选择同一轨道形成自身路由环。主总线原生编辑器目前检测主总线输入，没有独立的外部侧链来源选择。EQ 的动态检测、动态类效果、混响／延迟闪避、饱和动态、多段动态和滤波包络均有实际侧链处理路径。

效果器处理／导出沿用 Verdant 的固定 48 kHz 内部音频边界。单元测试中的其他采样率用于检查 DSP 数学与边界，不代表桌面宿主已经改成任意插件处理速率。宿主传输、延迟补偿、故障旁通、状态捕获和有限尾音导出策略见[音频效果器宿主](PLUGIN-HOST.md)。冻结或高反馈可能持续很久，不能用导出文件的有界尾音截止推断声音已经自然衰减。

原有参数自动化索引保持不变，新参数只追加。EQ 保留旧 43 个参数的顺序与 `output=24`，扩展频段和动态参数追加其后；Synth 的原有 14 个参数仍在开头。效果器状态为按参数 ID 保存的 JSON，通过宿主状态接口传输；在新实例中加载旧工程时，未提供的新增参数使用默认值。未知参数、非有限值或越界状态整体拒绝，不能留下已部分应用的状态。

原生自动化由控制侧发现并校验目标，在音频块中携带采样偏移；同一采样偏移的事件按提供顺序应用。前视会改变处理延迟，属于控制参数，不作为普通采样自动化目标开放。增益／频率等实时参数的自动化与鼠标拖动是两条不同路径：鼠标拖动在释放时提交，工程自动化在音频处理期间按采样偏移执行。
