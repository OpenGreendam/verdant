# Verdant 内置插件与默认原生界面

本套件提供 **12 个音频效果器、2 个音符乐器**，覆盖 FabFilter 当前 14 个产品家族所对应的处理类别。效果器在独立的 `verdant-plughost` 进程中处理音频，编辑器由 Verdant 桌面原生绘制；Synth 和 One 共用实时演奏、工程播放与导出的合成引擎。无需安装外部插件即可使用这些设备。所有内置设备默认打开自己的图形编辑器，并保留完整参数列表入口。

本文记录截至 2026-11-22 的实际代码能力、处理边界和验证入口。它们是 **Verdant 的独立实现**；功能类别和控件覆盖不表示与 FabFilter 专有算法、参数响应或声音逐样本等价。FabFilter 产品名仅说明功能参照，原厂商标图片、界面截图、插件二进制和出厂预设不随本套件分发。产品范围参考[官方产品目录](https://www.fabfilter.com/products)。

## 入口、Adwaita 外观与窗口生命周期

在轨道设备面板选择“添加效果器”，或从混音器的轨道／主总线插入位添加设备。内置效果器加载完成后默认打开原生窗口；再次打开同一实例会激活已有窗口。乐器轨支持 Verdant Synth 和 Verdant One，并有独立的原生乐器窗口和可演奏键盘。实例浏览器可以搜索工程内的轨道、主总线和乐器实例，并打开对应编辑器；无法提供原生窗口的外部乐器会明确显示不可用。

设备卡片与独立窗口共用编辑器、参数事务和历史。独立效果器窗口的“参数列表”与“图形界面”在同一窗口切换。支持编辑器的外部 CLAP、VST3、AU 仍打开其自己的宿主窗口；缺少编辑器时使用参数列表。内置设备不依赖第三方插件的 `has_editor` 标志。

外观遵循 Verdant 的 **Adwaita 风格**：统一浅色／深色主题、标题栏、圆角卡片、分段选择、清晰的文字单位、焦点与按下状态，字体优先 Adwaita Sans／Cantarell。频段颜色仅用于区分对象。内容缩放为 75–200%，可切换全屏；窄窗口通过滚动容纳全部控件。来源条固定在原生窗口工具区域，可将调制源拖到滚动正文中的参数。界面由 GPUI 绘制，不是 GTK/libadwaita 控件，也不声明 GNOME 一致性认证。

窗口绑定工程、文档世代与设备实例 UUID。插入重排后继续跟随原实例；移除、替换、切换工程或重新打开工程会使过期目标失效。旧工程中没有唯一实例 UUID 的插入使用当前 live key，避免旧窗口写入同槽的新设备。关闭窗口、失焦或取消拖动会释放捕获并丢弃未提交预览。乐器预览音符与外部 MIDI 的生命周期分开管理。

实现入口：[设备编辑器](../crates/verdant-app/src/devices.rs)、[套件控件](../crates/verdant-app/src/devices/suite.rs)、[编辑工作区与预设](../crates/verdant-app/src/devices/workflow.rs)、[原生窗口](../crates/verdant-app/src/plugin_editor.rs)、[参数事务](../crates/verdant-app/src/plugin_ui.rs)、[主题](../crates/verdant-app/src/theme.rs)。

## 通用操作与持久化工作区

| 操作 | 实际行为 |
|---|---|
| 拖动旋钮、曲线节点、XY 平面 | 本地预览，释放后提交一次事务和一次撤销步骤；未越过拖动阈值的点击不改变值。XY 同时提交两个坐标。 |
| Shift 拖动／键盘微调 | 缩小变化量；频率等宽范围正值参数按对数尺度调整。 |
| Alt 点击、双击控件 | 恢复原生默认值；EQ 空白图区双击用于新增／启用频段。 |
| 精确输入 | 支持与参数单位匹配的 `1.25 kHz`、`300 ms`、`0.3 s`、`-6 dB`、`50 %` 等。Enter 应用，Esc 取消。 |
| 方向键、加减按钮 | 遵守原生步长与枚举网格；连续参数可微调。 |
| 撤销／重做 | 使用工程历史，独立窗口支持 Ctrl/Cmd+Z 和 Shift+Ctrl/Cmd+Z。 |
| 旁通 | 卡片、插入菜单与原生窗口可切换；保留 DSP 参数。 |
| A／B、A→B、B→A | 两份参数快照按实例保存；整次宿主写入确认后才切换活动组。失败回滚，不把等待中的事务持久化。 |
| 干湿锁 | 加载预设时保留当前干湿比；其他预设参数照常应用。 |
| 初始化／重置 | 先使用当前设备完整默认值，再应用预设覆盖；重置使用全部原生默认值。 |
| 参考实例 | 选择其他实时效果器输出作频谱参考，可叠加、清除或用于 EQ Match。 |

精确输入、状态加载和自动化准入均检查有限值、范围及离散步长。失效设备身份、错误单位和整个无效参数批次被拒绝，不留下部分应用的状态。打开输入窗后若工程版本或设备身份改变，需要重新打开输入窗。

A/B、干湿锁、参考实例和部分编辑器展开状态保存在本地偏好中的 `device_workspaces`，以工程／所有者／实例身份索引；重建宿主或重开同一工程可恢复。它们**不是工程文件中的第二份可移植 DSP 状态**。工程仍保存当前实际参数；A/B 不包含旁通、侧链来源或窗口位置。旧版本参数快照按当前描述符补齐新增默认值；运行中的组切换在同一逻辑实例重建后继续确认，不能迁移到另一个实例。

### 用户预设与收藏

原生预设库支持命名、最多 16 个标签、多词搜索、收藏／仅看收藏、保存与更新、原生文件选择器导入导出，以及移动到回收目录的删除。预设使用 `.vpreset`，格式为 `verdant-device-preset` version 1；旧文件缺少 `favorite` 时默认为未收藏。收藏标记随预设文件导入导出。

用户预设按设备存入应用状态目录的 `plugin-presets/<device-id>`。读取限制为 1 MiB，检查设备身份、格式版本、名称、标签、全部参数 ID、范围和步长后才应用。文件 I/O 位于控制路径。

随包提供 **280 个原创原生预设，每台设备 20 个**。它们覆盖人声、对白、鼓组、贝斯、乐器、总线、母带、发送效果、创意、音色、调制、主音、键盘、铺底和序列等用途；每个预设有稳定 ID、分类、作者、描述和标签。加载时先补齐当前设备的全部默认参数，再应用配方，避免旧频段或隐藏参数残留。出厂库只读；调整后的音色可以另存为用户预设。搜索、分类、收藏和键盘选择同时支持出厂库与用户库，试听结束仅在实例仍处于该试听状态时还原，以免覆盖中途的手动编辑。

这些预设由 Verdant 独立制作，随本项目发行，可用于用户的音乐与音频作品；不含 FabFilter 出厂预设资产。校准运行对所有 280 个配方使用真实效果器／合成器状态载入和 PCM 渲染，检查全参数往返、设备内配方区别、有限值、有效音频和基准输入下的峰值余量。它不是对任意输入电平的防削波保证；阈值、门限、响度目标和发送干湿比仍应按节目素材调整。见[逐预设 PCM 收据](evidence/native-suite-followups-20261122/factory-presets.json)和[原生配方目录](../crates/verdant-plugins/src/factory_presets.json)。

## 音频编辑与 Agent 工作流

导入素材可进行源帧精度切分、双边范围切分、可还原裁剪、源内滑移、跨轨多选拖移、范围复制／剪切／粘贴、普通或波纹删除、连接、零交叉与静音切分、反向、变速、保音高 WSOLA、增益／声像、峰值标准化、线性／等功率淡入淡出与交叉淡化，以及选中片段 bounce。编辑保留原始源文件，通过工程历史撤销；界面、CLI 和 worker 共用同一原子编辑计划。详见[音频编辑说明](../../spec/AUDIO-EDITING.md)。

`verdant` 默认显示帮助并退出，`verdant gui` 显式启动桌面且默认返回；解包根目录的 `verdant-launcher`／`verdant-launcher.exe` 直接打开 GUI。`plugin.*`、`preset.*`、`mixer.*`、`clip.*`、`analysis.*` 和工程／渲染操作均可通过 CLI 或 `verdant worker --stdio` 的顺序 NDJSON 协议使用。完整 schema 包含原生参数单位和可自动化标志；修改要求检查 revision，批次先完整验证。乐器参数写入实际发声的 instrument params 状态，One 保留旧工程的未知扩展字段，同时只将其 187 个有效参数暴露给预设与参数检查。

随包 **128 个 Agent Skills** 包含 95 个 CLI 原子操作、32 个工程命令和一个总入口，可用 `verdant skill install --all --agent codex --scope project` 等方式离线安装。安装器验证完整清单和 SHA-256，拒绝覆盖用户改动，支持预览、幂等更新及卸载。详见[命令、worker 与 Skills](AGENT-AUTOMATION.md)。

## 实际信号、响度与增益历史

全部效果器显示宿主实际处理的输入与输出；Synth／One 显示实际合成 PCM。没有处理过音频时显示“等待音频”，样本停止更新超过一秒时显示“上次音频”。乐器无需播放工程时间线即可通过实时键盘／MIDI产生实际信号；不以循环动画伪造音频活动。

| 读数 | 来源与时间范围 |
|---|---|
| 左右采样峰值、未加权 RMS | 最近最多 2,048 帧；48 kHz 下约 42.7 ms。 |
| 输入／输出 FFT、参考实例频谱 | 同一近期 PCM 窗口，Hann 窗；平均左右功率，反相信号不会互相抵消。 |
| 波形 | 每 64 帧取立体声极值，最多 128 点，即 48 kHz 下约 170.7 ms；末段按实际长度显示。 |
| M／S LUFS | K 加权的 400 ms／3 s 滑动能量，启动窗口不足时补零。 |
| I LUFS | 400 ms 块、100 ms hop，绝对 −70 LUFS 和相对 −10 LU 门限，累积真实块能量；首个有效积分块在 400 ms 后产生。 |
| LRA | 3 s 块、100 ms hop，绝对 −70 LUFS 与相对 −20 LU 门限，10%／95% 分位差。 |
| True peak、最大 true peak | 每声道 4× FIR 重建；显示 dBTP。 |
| 最大 M／S | 自计量开始或重置后的最大有效响度。 |
| 内部增益历史 | 处理器实际提供的增益包络，每个完成的宿主处理块记录一次，最多 128 点；保留向上处理的正值。 |

响度积分和重建峰值**连续处理每个输出样本**，不会拿界面轮询得到的零散片段冒充整段测量。积分使用有界 0.01 LU 直方图累计能量和计数；LRA 同样使用有界统计。无有效响度或静音显示“−∞”；没有内部增益数据的设备不展示虚构 GR，输入与输出 RMS 的差也不会被标为压缩量。

这些计量依据 [EBU Tech 3341](https://tech.ebu.ch/docs/tech/tech3341.pdf)、[EBU Tech 3342](https://tech.ebu.ch/docs/tech/tech3342.pdf)所述 BS.1770／EBU 方法独立实现，带有校准、门限、LRA 与重建峰值测试；尚不构成标准机构认证或全套符合性报告。有限 FIR 的重建结果也不是任意连续时间波形的数学上界。

全部内置设备的“重置计量”操作重置该实例的响度积分、LRA、响度／重建峰值最大值与增益历史。Synth／One 通过专用音频事件立即发布复位结果，保留累计音频帧、PCM／波形历史、声部、琶音、调制和效果状态；复位后的声音与不复位的参考逐样本一致。乐器实时路径使用固定容量原子发布：首次有效捕获立即发布，之后最多约 30 Hz；每样本测量继续运行，后台读取与 FFT 不占用音频回调。频谱、波形、响度和 GR 来自同一有效快照，读取重试有界。

EQ 频响、压缩传输曲线、混响 RT60 模型、静态抽头与饱和曲线另行标识为参数模型；它们不代替实时 FFT 或真实增益包络。实现见[计量与原子快照](../crates/verdant-plugins/src/telemetry.rs)、[采样率质量与响度 DSP](../crates/verdant-plugins/src/builtin_dsp/quality.rs)、[信号显示](../crates/verdant-app/src/devices/signal.rs)。

## 共享调制与 MIDI Learn

每台设备有 8 条调制路由，来源、目标、双向深度和曲线分别可编辑。14 个实际来源为两路 LFO、音频包络跟随、触发包络、CC／调制轮、力度、键盘跟踪、压力、音色、X、Y、随机、弯音和步进。可从固定来源条拖放到参数，也可在矩阵中精确设置。目标以该设备可自动化参数为准；改变延迟或容量配置的控制参数不能作为实时调制目标。

两路 LFO 提供六种波形、自由速率／节拍、相位、时间平衡、同步倍率、输出电平与 MIDI 重触发。16 步 XLFO／步进提供长度、节拍、相位、平衡、全局及逐步滑移、逐步曲线／随机、半音吸附、输出电平和重触发。触发包络为 ADSR，支持 MIDI、音频或组合触发、音频阈值／迟滞及单极／双极输出；跟随器有峰值／RMS、输入增益和输出量。XY 是实际二维控制源。

8 个 MIDI Learn 槽保存 CC、通道过滤和目标。学习后参数值与路由通过同一状态接口保存，不只保留界面显示。控制端先把 MIDI 排入有界队列；所有串行控制请求先排空该队列再执行，因此紧随 MIDI 的保存不会越过已经排入的学习事件。停止、断开、队列溢出及目标切换具有释放／panic 路径，处理 All Sound Off、All Notes Off、Reset Controllers 和延音踏板，避免遗留触发包络或声音。

共享调制目标在 32 帧控制周期更新，最大额外量化为 31 个内部采样；这与工程自动化在指定采样偏移应用是不同的时序。Synth 的逐声部 MPE 表达独立于共享矩阵的最近 MIDI 来源值。实现见[调制 DSP](../crates/verdant-plugins/src/builtin_dsp/modulation.rs)和[实时合成器](../crates/verdant-plugins/src/builtin_dsp/synth_live.rs)。

## 逐设备处理与图形

### EQ

24 段均有启用、频率、增益、Q、形状、斜率、Stereo／Left／Right／Mid／Side 位置与独听。10 种形状为峰值、低架、低切、高架、高切、陷波、带通、倾斜架、全通和 Flat Tilt。Flat Tilt 由八个对数分布架式滤波器形成绕中心频率归零的倾斜；全通保留幅度目标并改变相位。

旧离散切除斜率索引保持 `[12, 24, 36, 48, 6, 18, 30, 60, 72, 84, 96]` dB/oct。每段新增连续斜率开关与 0–96 dB/oct 值；峰值／陷波有效下限 12，切除／带通下限 0，其余形状下限 6。连续斜率使用广义连续阶数的幅度目标，Brickwall 为独立高／低切目标。连续形状、Flat Tilt 与原厂算法不构成逐系数等同。官方控件范围参照 [Band controls](https://www.fabfilter.com/help/pro-q/using/bandcontrols)。

动态提供正负最大范围、阈值、启动、释放和外部侧链；普通线性相位动态在带内检测，Spectral EQ 在 STFT 频点上检测，density 改变检测邻域，tilt 改变频率倾斜。静态曲线使用实际滤波目标／系数，动态边界虚线表示所设范围；实时动作由 PCM 与增益数据表达。

| 路径 | 实际实现与固定延迟（内部帧） |
|---|---|
| 零延迟／原有路径 | IIR，0 帧；仅开启 Spectral 时另加 2,048 帧。 |
| Natural | 33 tap 半带 2× IIR 往返，16 帧；Spectral 另加 2,048 帧。 |
| Linear，或任一 Brickwall／连续斜率开关 | 共用 FIR＋STFT，三档分辨率总延迟为 2,432／3,200／4,224 帧。即使该频段旁通，开关仍预留这条路径，避免动态启停改变延迟。 |

有限长度 FIR 的低频、高 Q 和相位精度取决于分辨率；图中目标不等于无限长理想滤波器。自动增益由静态频响估计，不是节目响度标准化。

FIR 路径的频率、增益、Q、形状、连续斜率数值和独听自动化先合并为一致的目标快照。处理器按自己的 **32 帧时钟**分阶段设计，完成后在 **128 帧卷积边界**发布；同一调制 tick 的多次写入不会分别重建整套滤波器，任意宿主分块不会重置这个时钟。构建中的快照不被新写入反复打断，后续设计读取最新目标，因而持续调制也不会饿死实际更新。输入 FFT 历史、overlap 和已经排队的输出保留，所有缓冲在构造时分配。

最复杂的四路径、高分辨率快照需要最多 **89 个 32 帧工作片**，发布再等至多 127 帧边界对齐；48 kHz 下单次核设计／发布保守不超过 **62 ms**，连续写入停止后最后目标至多经过当前及下一次设计，保守不超过 **125 ms**。这是核更新窗口，不是新增的音频延迟；已排队的音频仍按上表的固定 FIR／STFT 延迟输出。快速 LFO 在这些快照时刻采样目标，不提供逐采样滤波器 FM，也没有额外的参数平滑器。首次静态状态和相位／分辨率等固定控制同步设计，使第一段有效输出和声明延迟匹配；普通 IIR、动态检测和输出增益继续使用各自原有处理时钟。


双击空白图启用频段，拖动频率／增益节点、频谱峰值抓取、自由绘制 Sketch 都实际写入参数。Sketch 与跨实例 EQ Match 使用最多 24 个 Bell／低架／高架候选，按实际采样率和 biquad 系数联合优化重叠频段的残差。Match 只使用源／参考共同测得的频率范围，可设匹配 Hz 范围、0–100% 强度、平滑宽度、最大频段数和整体电平差移除；受限边缘渐变回零。原生窗口在后台拟合，显示实际频段数、RMS 与最大 dB 误差，计算期间发生的新参数修改不会被旧结果覆盖。纯分析接口与 CLI／worker 的 analysis.eq-fit、analysis.eq-match 使用同一实现。确定性四段目标的六段拟合 RMS 为 0.06098 dB，独立频点的实际 PCM 最大误差 0.11705 dB；这是指定实验结果，不是任意输入的误差上限，也不承诺逐样本音色复制。算法与报告定义见 [原生分析说明](native-plugin-analysis.md)。

### Compressor

阈值、比率、软拐点、最大范围、启动／保持／释放、前视、补偿、输入／输出和干湿比之外，提供 14 个独立风格：干净、平滑、冲击、人声、总线、光学、向上、泵动、多用途、三段双向、Op-El、Vari-Mu、经典和母带。反馈检测、三段处理、静态增益函数与时间行为实际不同；三段双向使用 90 Hz／2.5 kHz 分区。风格类别参照 [Style and character](https://www.fabfilter.com/help/pro-c/using/styleandcharacter)，不宣称复现其专有电路模型。

自动阈值按输入 RMS、目标衰减和追踪速率更新；自动释放与自动补偿各有实际处理。检测区提供峰值／RMS、高低切、6 段可开关侧链 EQ、侧链 Stereo／Mid／Side／Left／Right 选择、监听、立体声联动，以及主处理 Stereo／Mid／Side。6 节点图使用同一侧链滤波系数。

MIDI 音符或节拍可触发，设定触发长度、节拍和回退 BPM。关闭、电子管、二极管、明亮四种 character 可在压缩前／后施加。2×–32× 过采样处理非线性路径；干声跟随前视与质量延迟。传输曲线使用同一风格静态增益函数，但不表达全部谐波或包络历史。

### Gate

经典、干净、人声、吉他、向上、闪避六种风格具有实际增益和释放行为；包括阈值、比率、范围、软拐点、迟滞、启动、保持、释放、前视、干湿与输出。迟滞设置开／关门的不同阈值，保持防止立即闭门。

检测包含峰值／RMS、程序相关释放、侧链高低切、Stereo／Mid／Side／Left／Right 选键、监听和立体声联动。主处理的 Stereo／Mid／Side 与检测声道选择独立。侧链监听输出真正被选择的检测信号。阈值节点和传输图写入相同 DSP 参数，实际增益历史来自处理器包络。

### De-esser

全带模式降低完整信号，分频模式降低高频支路。全能、人声和自适应检测使用检测频带、能量比例及多频带谱平坦度；敏感度、瞬态保护、保持、攻击／释放、频带上下限和最大衰减均参与检测。可用外部侧链、监听、声道联动和 M/S 处理。

相位可选 IIR 或 129 tap 线性互补分频；线性路径增加 64 帧，再加前视。干声按同样延迟对齐，不把 dry=0 的路径强行送过 IIR 分频重组。自适应识别是 Verdant 的检测规则，不是原厂语音分类器。

### Limiter

透明、平滑、冲击、安全、激进、现代、总线、动态八种风格改变高采样率增益引擎的包络行为。前视使用固定容量滑动最小队列，另有启动平滑、释放、声道联动、直流滤除、反向输入增益比较和差分监听。侧链可增加衰减，主信号峰值仍参与保护。

音频与检测路径一同 2×–32× 过采样。重建峰值保护至少启用 4×，通过 FIR 各支撑区间的绝对贡献上界约束动态增益后的输出；这种保守保护可能比单纯采样峰值限制衰减更多。保护的保证范围是本实现所采用的 4× 重建器及测试条件，不是所有 DAC 重建滤波器。

响度目标使用连续测得的输入短时响度，以约 1 s 平滑追踪目标，增益校正有 ±24 dB 上限；目标可能因限制上限、输入动态或最大校正量而无法达到。抖动支持关闭、TPDF、轻／强噪声整形，8–24 bit；关闭时不量化。抖动预留峰值余量。反向输入增益比较与启用响度目标是两个独立选项。

暂停积分同步控制内部输入／输出表和宿主显示表的 I／LRA，M／S 与峰值继续追踪实际音频。参数复位仅在上升沿生效；工具栏复位同时重置内部与显示计量，并保留处理器音频、前视、增益包络与目标增益平滑。共享信号区显示宿主输出的持续 LUFS／LRA／true peak。前视、过采样和重建峰值改变处理延迟，属于控制参数；默认 48 kHz、3 ms 前视为 144 帧，质量路径另加 32 帧，ISP 保护再加 32 帧。

### Reverb

核心为 8 线反馈延迟网络，现代／复古／板式三种风格，五种房间延迟族连续插值。预延迟、衰减、尺寸、阻尼、扩散、宽度、调制、距离、厚度、早期反射和声源位置均改变实际处理。冻结停止新输入并保留池内反馈；输入或外部侧链驱动闪避。

8 个任意衰减节点支持 Bell／低架／高架，控制各反馈线的频率相关 RT60 比率；8 个后置节点支持 Bell、架式和切除。原有低／高衰减与后置音色参数仍保留，正衰减节点叠加时作稳定归一化，避免不受约束的反馈增长。预延迟和门限时间可按节拍同步，门限另有阈值和释放。

IR 导入分析单声道 PCM（64 样本至 60 s，8–384 kHz），估计稳定尾噪并从 Schroeder 反向积分中扣除，在高于噪底的 −5 至 −35 dB 区间回归 RT60，要求至少 10 dB 有效衰减跨度。最多八个倍频程测量按分析滤波器实际等效噪声带宽归一能量，联合拟合真实 FDN 的频率相关衰减节点与后置 EQ；前 80 ms 的能量和回声密度用于早反射量／扩散的整体特征近似。报告返回输入 RT60、r²、有效跨度、噪底、各频带可靠测量与模型 RMS 百分比误差，GUI 与 analysis.reverb-ir CLI／worker 共用实现。含尾噪的 1.2 s 确定性 IR 测得 1.2027 s；另一 0.85 s 目标经拟合后实际 FDN PCM 测得 0.85815 s。静音、非有限值、无足够衰减和明显非瞬态输入被拒绝。**这是算法混响参数拟合，不是卷积播放原 IR**；不重建每个反射的时间、相位和方向。图中反馈模型与输入 IR 测量分别报告，具体算法、边界及量化条件见 [原生分析说明](native-plugin-analysis.md)。

### Delay

主回声加 15 个独立抽头，各有启用、电平、声像和相对时间；图中抽头可选中并拖动。自由时间与节拍、左右偏移、附点／三连音、乒乓／交叉、LR／MS／串联路由、反馈旋转、扩散、Lo-fi、驱动、动态量、冻结和闪避均进入实际音频。

磁带模式改变读头速度与时间；伸缩使用双读头交叉淡化；反向使用双 Hann 窗反向粒度。双 IIR 滤波器支持串联／并联／逐声道，反馈 character 包含磁带、电子管、atan。反馈移调和镜像移调使用双窗读取。0／2×／4×／8×／16×／32× 质量作用于反馈回路。

宿主 through 延迟为零；过采样产生的 32 帧位于反馈回路，首个回声不变，后续每绕一圈增加对应延迟。延迟线固定为 54 s；极慢磁带速度、低 BPM 与大拍数组合可能达到容量上限。静态图表达设定时间／电平与计算模型，不把参数模型称为实际活动回声。

宿主速度经独立传输事件进入 DSP，支持 20–1,000 BPM，回退 BPM 保留 20–300 范围；同步时低于支持下限的工程速度明确拒绝。传输事件按上游实际延迟对齐并支持稳定循环回绕。跳转不清空既有反馈和桥接缓冲，因此残留尾音仍受之前状态影响。

### Saturation

最多 6 段、28 个独立失真风格，覆盖磁带、电子管、削波、折返、整流、变压器、放大器、位深与带状态的 smudge／倍低八度／破坏型处理。每段有驱动、继承或独立风格、音色、干湿、电平、声像、动态量、独听／静音，另有反馈／反馈频率、驱动平衡、低中高／presence 与声道位置。

全局与逐段 LR／MS、最高 32× 过采样、最小相位或线性互补分频都实际参与处理。线性分频延迟 64 帧，启用质量路径另加 32 帧，干声同步对齐。箱体选择包括关闭、开放 combo、封闭 4×12、贝斯与收音机，由实际滤波器实现；不冒充原厂放大器或测量箱体 IR。

中性设置按互补分频重组。关闭某段处理恢复该段干声，静音仍会排除该段；段电平／声像作用于段内混合结果。静态传输图直接使用无状态曲线助手，不在每次绘制时构造 DSP；反馈、包络、倍低八度和记忆型处理无法由一条无状态曲线完整表示。

### Multiband

1–6 段可用相邻分频或任意悬空／重叠范围。每段有阈值、正负范围、比率、攻击／释放、软拐点、增益、压缩／扩展、独听／静音、频率上下限、斜率、独立检测上下限／来源、立体声联动、LR／MS 放置和 0–20 ms 前视。外部检测音频不混入主输出。

Dynamic 路径以干声加差分处理保持 unity 干声；Minimum 路径保留固定 IIR 分频相位旋转；Linear 使用逐段 513 tap FIR、384 帧，干湿相同延迟。悬空范围使用最多八节 IIR，重叠频段确实叠加处理；三种模式是 Verdant 自己的实现，不等于 Pro-MB 专有相位算法。

2×／4× 质量路径增加 32 帧。总延迟为各段最大前视＋线性模式 384 帧＋质量 32 帧。静态范围图、动态边界和实际增益历史分别显示，不能把上下限曲线误作实时增益。

Linear 路径中的分频频率、悬空上下限、斜率和布局改变同样使用分阶段 FIR 目标。全部六段共享一个 **每 32 帧只执行一个工作片**的轮转预算，每段快照需 13 片，六段同时变化最多 2,496 工作帧，再等至多 127 帧发布边界。48 kHz 下单次快照保守在 **56 ms** 内发布；连续写入停止后的最新目标保守在 **112 ms** 内发布。每段保留一致快照、卷积历史与既定延迟，隐藏的线性频段也随同一音频帧推进，以便重新启用时保持时间对齐。初始状态与固定相位切换同步完成；阈值、动态增益和检测器不等待 FIR 设计。


### Filter、Dual Filter 与 Micro Filter

Filter／Dual Filter 分别有 4／2 个单元，提供低通、高通、带通、陷波、低架、高架、Bell、全通八形状。每单元有开关、频率、共振、斜率、驱动、11 种非线性 character、反馈、声像、电平及适用的 EQ 增益。组合路由为串联、并联、并联对和交错立体声，另有全局 LR／MS。

Micro 为一个低通／高通单元，提供同一套 character、反馈、滤波电平、声像、声道方式与包络控制，不开放无意义的 Bell 增益。三台设备均有实际包络调制，共享矩阵扩展更多来源，最高 32× 全滤波组过采样和 32 帧干声对齐。

小信号频响使用真实滤波系数、路由功率组合与反馈线性化；图不包含有限重采样 FIR 的全部响应，也不能表示强驱动、时间调制或非线性自激的完整声音。

### Synth 与 One

Synth 使用 4 振荡器、4 波形、5 振荡器模型、噪声，最多 64 音符声部和每音符 8 路齐奏。4 滤波器具低通／高通／带通／陷波、声像、串并联和 6 种 character。ADSR、LFO、滑音、键盘跟踪、力度、失谐、宽度均参与声音；六效果区包括驱动、chorus、phaser／flanger、delay、算法 reverb 和 compressor。质量选项为关闭／2×／4×。

琶音器有自由速率／节拍、5 种顺序、1–3 八度、gate、swing、三态 latch：关闭、物理按键全部释放后由下一和弦替换、和弦累加。物理按键位图与 latch 独立，长时间闲置后触键不会追赶过期节拍产生密集突发。

One 仅接受自己的 **23 个基础参数**，单振荡器、单滤波器、最多 10 复音，另有共享 164 参数调制。它不会通过旧状态偷偷启用第二至第四振荡器、多个滤波器、Synth 效果、MPE 或琶音器；有独立振荡器模型、滤波 character、弯音范围及常用 ADSR／LFO／滑音控制。

实时键盘、外部 MIDI、工程音符与导出使用同一 `RealtimeSynth`。音符携带力度和通道，CC、弯音、通道压力、复音压力、NoteOff 与速度事件按采样偏移进入合成器。工程表达保存于音符扩展数据 `midi_expression` 并往返保存；渲染缓存包含表达和速度。Synth MPE 使用主通道与成员通道的弯音／压力、成员 CC74 和独立复音压力；复音压力不篡改原音符力度。持音时更新合法参数保留声部，不重建整台乐器。

内部乐器可在暂停播放时演奏并送到声卡输出；内部固定速率与声卡速率不同时，监听具有独立重采样时钟。当前第三方 hosted instrument 对非零通道／表达尚不支持的请求会明确报错，不静默丢弃。这不表示所有平台、所有实体 MIDI 设备已经实机验收。

## FabFilter 预设互操作

`.ffp` 导入是**有边界的参数翻译**，不是直接加载原厂 DSP 状态。文件先由 [`preset_interop.rs`](../crates/verdant-plugins/src/preset_interop.rs) 检查，再显示产品、版本、转换参数、warnings 和 unsupported。存在未表达功能时，只有用户选择“导入转换预设”才生成 Verdant 用户预设；未映射项采用明确标示的 Verdant 默认值。仅识别格式、没有可转换参数的文件不能导入。

| 格式 | 已验证的转换范围 | 明确保留的限制 |
|---|---|---|
| Pro-Q 3 `FQ3p` v4 二进制 | 精确头部／334 个 float 结构，24 段与全局静态 EQ 的已知物理映射；小端、长度、有限值检查。 | 当前出厂语料不含 Q3；结构以源码参考及合成测试覆盖。未知斜率／动态等字段报告 unsupported。 |
| Pro-Q 4 `FQ4p` v4 文本 | 24 段静态频率／增益／Q／形状／声道、相位／分辨率及已验证全局项；Flat Tilt／AllPass 正确映射本机不同索引。 | 动态／频谱检测的归一化阈值和时间等未知映射不启用，明确报告；character、未知全局项和未验证编码同样报告。 |
| Pro-C 3 `FC3p` v2 文本 | 已知风格、阈值／0–72 dB knee／range、部分自动开关、干湿、Character 模式／−24…24 dB Drive／Pre-Post 与 6 段侧链 EQ。 | ratio、attack／release、stereo link 等尚未验证的归一化到物理值变换不猜测，均为部分转换。 |
| Pro-R 2 `FR2p` v6 文本 | 已知 mix、gate、style、decay rate、distance／thickness、freeze、Ducking dB、Stereo Width 百分比与衰减／后置 EQ 节点。 | space、brightness、character 与部分时间模型仍有诊断；宽度保留百分比并警告原厂内部互馈和本机算法的差别。 |
| Pro-MB `FPMb` v3 二进制 | 精确 150 个 float、6×22 频段布局；悬空范围、state、阈值、range／knee／gain／mode、lookahead、mix／output 的已知映射。 | ratio 使用已测表插值并警告近似；attack／release 的程序相关百分比不能直接当毫秒，斜率／侧链／联动／相位未验证项报告。 |
| 其他识别到的版本 | 识别 One、Pro-G／DS／L 2、旧 Pro-R、Saturn／Saturn 2、Timeless 3、Volcano 3、Twin 3、Simplon／Micro 等签名和头部版本。 | 尚无可靠参数布局的二进制只返回诊断，不生成假转换。未知签名／版本拒绝。 |

Q4 已验证斜率编码为 `[0, 6, 12, 18, 24, 30, 36, 48, 72, 96, Brickwall]`，另验证 raw 0.5 对应 3 dB/oct；其余未经验证的小数编码不取整猜测。超出本机频率／Q 等可表示范围的关键频段被禁用并报告，不静默钳位。全部参数缺省值与真实映射项在界面中称“转换结果”，不会把补入的默认值都称为成功映射。

解析限制为 1 MiB、4,096 字段／行和单行 16 KiB；重复字段／段、非有限数字、截断、错误设备和未知版本会在应用前拒绝。严格接口 `import_fabfilter_preset` 在有 unsupported 时原子拒绝；预览接口 `inspect_fabfilter_preset` 才允许显式查看并选择部分翻译。

## 侧链、自动化、延迟与实时约束

轨道侧链选择另一轨道的**插入前**信号，“无”表示检测当前输入；同轨自循环禁止。主总线也有外部侧链来源入口。EQ 动态、各动态效果、空间／延迟闪避、饱和动态、多段独立检测和滤波包络均连接真实侧链 PCM，检测音频不会直接混入主输出。

桌面实时效果链维持 **48 kHz、立体声**处理，输出适配器按实际声卡采样率转换。离线导出可在 **44.1／48／88.2／96／192 kHz** 原生运行素材准备、合成器、轨道／主总线插入、自动化和延迟补偿；插件按所选采样率实例化，不统一先在 48 kHz 处理后重采样。离线实例不进入实时图，实例生命周期内的采样时钟固定，切换导出采样率会建立新实例。实际独立宿主 Delay 的五档采样率输出已与同采样率直接 DSP 逐样本核对。环绕声／Dolby Atmos 多通道总线及空间对象宿主仍不在当前立体声图中。宿主延迟补偿、故障旁通、状态捕获和有限尾音策略见[音频效果器宿主](PLUGIN-HOST.md)。

老参数索引保持不变，新参数追加；EQ 仍保留最早 43 参数顺序和 `output=24`，Synth 原有 14 参数仍在前部。效果器状态按参数 ID 保存，通过宿主接口传输；旧状态未提供的新增项使用默认值。未知、越界、非有限或离散网格外的值整体拒绝。鼠标事务在释放时提交，工程自动化按采样偏移应用，同偏移事件按给定顺序执行。

改变延迟／容量或固定路径的控制不作为普通自动化与 MIDI Learn／调制目标开放：例如前视、过采样、EQ 相位／分辨率／Spectral／Brickwall／连续斜率开关、DS 分频相位、Saturation 线性分频、多段相位、Synth 高质量。Limiter 的计量暂停／复位也作为控制操作，在完整处理块边界同步内部与显示状态。EQ 连续斜率数值在预留好 FIR 路径后可实时更新。延迟由宿主重新查询和补偿，干声、旁通对齐与末尾处理仍遵循宿主协议。

音频路径使用预先分配的缓冲、固定容量队列和原子遥测；采样处理与已准入事件不应分配或释放堆内存。大型过采样历史在构建阶段放到堆上，避免默认线程栈溢出。监听源交换与退休分开，旧合成器在非回调路径销毁；停止队列满时保留待停止请求并重试。参数批次先完整校验再修改处理器，不能一半生效后才发现后半无效。

冻结和高反馈可能持续远长于导出的有界尾音上限；文件结束不等于真实尾音自然衰减。高倍率过采样、24 段 FIR／Spectral、64 复音×8 路齐奏和密集调制均有实际 CPU 成本，功能与零分配测试不等于所有参数同时开启时满足任意硬件的实时预算。

## 实现与验证边界

原先未实现的共享调制、MIDI Learn、用户预设／收藏、A/B 持久化、湿声锁、实例浏览器、缩放／全屏、实际乐器计量，以及各家族上述高级 DSP 已有真实代码路径。以下边界仍须在合入说明和用户界面中准确保留：

| 范围 | 当前边界 |
|---|---|
| 商业算法 | 14 个类别及其功能是独立实现；没有获得专有算法、所有风格的原厂音色／参数一致性证明。 |
| 预设 | 已验证 Q3／Q4／C3／R2／MB 的明确子集；部分转换须预览，其他二进制多数仅识别，未知 active 项不静默丢弃。 |
| 通道 | 当前宿主为立体声；M/S 是立体声变换，不能称为环绕声或 Dolby Atmos。 |
| 响度与峰值 | 连续 PCM 计量、门限与重建测试已实现；没有完整认证报告，有限 FIR 不是任意模拟重建的保证。 |
| IR 与匹配 | IR 提供去噪衰减／频率／早期特征与实际 FDN 模型误差；EQ Match／Sketch 是最多 24 个 Bell／架式频段的联合拟合并报告误差。仍是受限参数模型，不是卷积或音色逐样本复制。 |
| 实时性能 | 有界内存、原子快照与分配计数测试不替代设备上的极端负载／驱动延迟测试。 |
| 第三方乐器 | 不支持的通道／表达会明确拒绝；原生内置演奏能力不自动扩展为任意第三方格式的 MPE 支持。 |
| 平台与辅助功能 | 按实际回执记录 Linux／Windows／macOS、物理 MIDI／声卡、IME、屏幕阅读器和窗口事件；没有运行的项目不能写成已通过。 |

## 可重复验证入口

以下命令是验证入口，不替代对应提交的最终运行回执。测试代码覆盖实际 PCM、状态往返、时间边界和错误原子性；具体总数以合入记录为准。纯 DSP／遥测测试使用 `--lib`，避免关闭默认客户端特性时误编译依赖客户端的集成测试。

```sh
cd frontend
cargo test --offline -p verdant-plugins --no-default-features --lib builtin_dsp
cargo test --offline -p verdant-plugins --no-default-features --lib telemetry
cargo test --offline -p verdant-plugins --no-default-features --lib preset_interop
cargo test --offline -p verdant-plughost --test builtin_suite
cargo test --offline -p verdant-plughost --lib
cargo test --offline -p verdant-app devices::
cargo test --offline -p verdant-app plugin_editor::
cargo check --offline -p verdant-app -p verdant-plughost
```

EQ／Multiband 的 FIR 调制预算可用公开 DSP API 独立复测；此入口只打印实测时间，**没有 CI 内定时阈值断言**：

```sh
cargo run --offline --release -p verdant-plugins --no-default-features \
  --example native_fir_budget -- --ticks 1500 --frames 32 \
  --json /tmp/native-fir-budget.json
```

示例固定 48 kHz／立体声，覆盖单段 Linear、单段连续斜率、八段 Linear／每 tick 八次写入、24 段高分辨率连续斜率／八次写入，以及六段 Linear Multiband／八次写入。可用 `--ticks 1200` 重复，`--frames` 指定每次处理的帧数；初始化和静态状态安装不计入计时，帧零调制及后续实际 PCM 处理计入。输出配置、总耗时、wall median／p95／max、RTF 与可选 JSON。32 帧在 48 kHz 的时限为 0.667 ms，RTF < 1 只表示总处理速度快于音频时长；wall max 含操作系统调度，不是硬实时证明，也不代表其他硬件、并发轨数或所有动态／过采样选项的性能保证。相关实现与回归见 [FIR 预算示例](../crates/verdant-plugins/examples/native_fir_budget.rs)、[EQ](../crates/verdant-plugins/src/builtin_dsp/eq.rs)、[多段动态](../crates/verdant-plugins/src/builtin_dsp/multiband.rs)。

合法取得官方语料后可单独运行：

```sh
VERDANT_FFP_REFERENCE_ROOT=/absolute/path/to/factory-presets \
  cargo test --offline -p verdant-plugins --no-default-features --lib \
  preset_interop::tests::external_factory_corpus_probe -- --ignored --nocapture
```
