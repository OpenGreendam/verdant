# 原生 EQ 与 IR 分析：算法、接口和量化验收

2026-11-22。实现位于 [EQ 拟合](../crates/verdant-plugins/src/builtin_dsp/eq/fit.rs)、[IR 拟合](../crates/verdant-plugins/src/builtin_dsp/space/ir_fit.rs) 和 [原生分析窗口](../crates/verdant-app/src/devices/analysis_tools.rs)。这些是 Verdant 的独立实现，输出可继续编辑的内置插件参数。

## EQ Sketch / Match

旧实现逐次找到最大残差，只添加 Bell 并相减一次。新实现选择 Bell、低架、高架候选，用实际音频处理器的 biquad 系数计算响应；每加入一个频段后重新优化已有频段，最后联合细化。这样能处理重叠频段之间的影响，并用架式频段表示频谱两端的持续增益。

计算使用 256 个等对数频率探针，按实际处理采样率计算系数；拟合上限为 20 kHz 与 0.475×采样率中较低者。最大 24 段，每段频率、增益、Q 都受设备范围限制。绘制曲线的有效增益限制在 ±24 dB。返回的修改关闭旧频段的动态／Spectral／Brickwall／连续陡度模式，清除独听、自动增益并将输出归零，然后启用拟合的静态频段；参数应用仍是一个可撤销事务。

Match 使用实际测得的源输入频谱和参考输出频谱。只匹配两份数据共同覆盖的频率，并提供：

- 任意 20 Hz–20 kHz 范围；不足 5% 频率跨度时拒绝。
- 0–100% 匹配强度。
- 0–2 octave 的高斯平滑宽度；宽度定义为半高全宽。原生窗口提供关闭、1/6、1/3、1 octave。
- 可选移除整体电平差，以单独匹配音色。
- 1–24 个最大频段。
- 受限频率边缘用 1/4 octave 渐变回到零修正，避免匹配范围突然截断。

### 公共接口

```rust
eq_fit_curve_report(points, max_bands, sample_rate) -> Result<EqFitReport, String>
eq_match_spectra_with_options(source, reference, EqMatchOptions) -> Result<EqFitReport, String>
```

原有 `eq_fit_curve` 和 `eq_match_spectra` 返回参数列表的入口仍保留。选项与报告支持 serde 序列化。CLI／worker 的纯分析操作为 `analysis.eq-fit`、`analysis.eq-match`；可将结果交给原子参数写入操作。

| 报告字段 | 含义 |
| --- | --- |
| `parameters` | 可提交的 ID／数值列表 |
| `bands_used` | 实际启用频段数，平坦目标可以为 0 |
| `rms_error_db` | 对数探针网格上的静态响应 RMS 误差 |
| `max_error_db` | 同一网格上的最大绝对误差 |
| `level_offset_db` | Match 移除的整体电平差；Sketch 为 0 |

误差相对于经过范围、平滑和强度处理后的目标。RMS 使用完整拟合网格，包括受限范围外的零修正区域，最大误差同时提供，避免只看平均值。测得的快照不代表整首歌的长期平均频谱；用户仍需播放有代表性的节目。曲线拟合也不会复制参考音频的动态、相位、空间或非线性特性。

### 原生交互

Sketch 在后台计算，完成后叠加拟合曲线，并显示频段数、RMS 与最大误差。Match 的范围、强度、频段上限与平滑可在原生窗口中调整。两种计算在完成时检查工程代际、实例身份以及原参数是否仍相同；绘制内容改变也会使旧 Sketch 结果失效。后台工作不会覆盖用户随后完成的新修改。

## IR 参数拟合

IR 分析仍返回算法混响设置，音频文件不会成为卷积核。输入限制为有限单声道 PCM，64 样本至 60 秒，8–384 kHz。GUI 和音频分析入口负责解码／处理声道；静音、无足够衰减、非有限值、明显非瞬态内容会返回错误。

本次改进分为四部分：

1. **衰减与噪底。** 按 5 ms 能量块分析，只把末段趋于稳定的能量平台当作录音噪声，从反向积分中扣除。仍在衰减的尾部不被直接当作噪底。用高于噪底的 −5 至 −35 dB 能量衰减区间回归，要求至少 10 dB 有效跨度和 r²≥0.8，输出实测 RT60、拟合 r²、跨度及噪底。
2. **频率能量。** 在最多八个倍频程中心测量频率相关衰减。每个分析滤波器的等效噪声带宽用其实际冲激响应平方和计算，按 Parseval 关系归一；因此白色衰减尾不会仅因高频带宽更宽而被错误拟合成高频更亮的音色。
3. **反馈模型。** 联合优化衰减节点，使真实 FDN 的频率衰减模型接近测量值。基础衰减取可表示的较长尾部，再用衰减型节点缩短不同频带，避免独立正节点叠加触发稳定归一化后影响无关区域。后置音色也通过联合 EQ 拟合，而非把每个带能量直接当作一个互不影响的 Bell 增益。
4. **早期特征。** 测量前 80 ms 的能量占比，并用超出指数尾部预期的早期能量设置早反射量；前段归一化回声密度用于扩散。它们是整体特征的启发式近似，不重建每个离散反射的时间、相位或方向。

### 公共接口

```rust
fit_reverb_ir_report(samples, sample_rate) -> Result<ReverbIrFitReport, String>
```

原有 `fit_reverb_ir` 返回参数列表的入口仍保留。CLI／worker 的纯分析操作为 `analysis.reverb-ir`。

| 报告字段 | 含义 |
| --- | --- |
| `parameters` | 可继续编辑、可原子提交的混响设置 |
| `predelay_ms` | 测得的输入 IR 起始延迟；控件仍有 250 ms 上限 |
| `decay_seconds` | 输入 IR 的全带实测 RT60，不是直接复制显示中的基础衰减旋钮 |
| `decay_r_squared` / `decay_span_db` | 衰减回归质量与实际使用的动态范围 |
| `noise_floor_dbfs` | 估计的稳定尾噪；未测得时报告下界 −160 dBFS |
| `early_energy_percent` | 去噪后前 80 ms 的能量占比 |
| `decay_model_rms_percent` | FDN 频率衰减模型相对有效测量频带的 RMS 百分比误差 |
| `bands` | 各频带中心、可选 RT60／r²、带宽归一后的相对能量 |

信号不足的频带以 `None` 表示衰减测量，不能把缺乏可靠测量的频带说成已经精确匹配。模型与控件有边界：基础衰减 0.2–20 s、节点比例范围、有限频带及固定 FDN 结构都会限制精度。报告保留实际误差；这不构成卷积重建、空间测量认证或原厂算法等价声明。

## 实际量化结果

运行：

```sh
cargo test --offline --locked -p verdant-plugins fit::tests -- --nocapture
```

本次 7 个新增回归全部通过。完整日志见 [测试证据](evidence/native-suite-aesthetics-20261122/analysis-fit-quality-tests.log)。

| 实验 | 实际结果 | 检查目的 |
| --- | --- | --- |
| 低架＋两个重叠 Bell＋高架，最多 6 段拟合 | RMS **0.06098 dB**；最大 **0.20041 dB** | 联合频段与架式候选的静态响应质量 |
| 同目标的 10 个未用于采样的频点，实际 EQ 处理 PCM | 最大幅度误差 **0.11705 dB** | 验证音频处理结果，不只比较画布模型 |
| 200–6000 Hz、50% 强度、1/4 octave 平滑 | 40 Hz **−0.0097 dB**；16 kHz **−0.0066 dB** | 受限范围外接近零修正 |
| 已知 1.2 s 指数尾＋独立稳定尾噪 | **1.2027 s**；r² **0.999977**；有效跨度 **29.70 dB**；噪底 **−52.76 dBFS** | 噪声不把尾长测量显著拉长 |

测试还覆盖 44.1／96 kHz 系数差异、零匹配强度、非法范围和重复频率输入。以上是确定性信号与指定条件下的结果，不能推广为任意录音和任意频响的统一误差上限。
