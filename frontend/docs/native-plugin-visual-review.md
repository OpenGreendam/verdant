## 共同改进

- Adwaita 的中性明暗表面、系统字体、选中描边与强调色保留；插件表面显式使用无衬线 CJK 回退链，避免未覆盖字形落入衬线字体。没有导入 FabFilter 的商标、皮肤、旋钮图片或截图资产。
- 原生窗口标题条由 56 缩为 48 基准像素。MIDI、实例、缩放和全屏放在“工具”展开行，默认主界面更集中。
- A/B、复制比较、起始设置、预设库、干湿锁和重置仍在同一共享工具条。新增“编辑／高级／计量”分区，状态跟随工程中的逻辑实例。
- 高级参数按处理用途分组并可展开。原有参数列表回退也对两种乐器开放；分层不会删除参数。
- 频率图注解加大并提高对比度。主控制数值仍支持精确输入、键盘调节、Shift 微调、默认值复位与一次拖动一个历史事务。
- 真实计量在首屏以简短输入／输出读数显示，完整 FFT、波形、响度、真峰值和内部增益历史进入“计量”。没有音频时明确等待；停止后标明上次音频。
- 合成器键盘从滚动内容开头移到底部，可收起；白／黑键使用专门的键盘主题颜色。按键去重、keyup、窗口失焦和关闭时的释放路径保留。

## 预设工作流

内置库来自 `verdant_plugins::factory_presets`，在打开浏览器时缓存。所有原厂条目只读，收藏使用稳定 ID 存入本地偏好；用户预设收藏仍保存在其文件中。

浏览器提供类别、来源和收藏筛选；名称、作者、类别、标签及用途说明统一搜索。选中后显示作者和使用建议，方向键浏览，Enter 载入试听。试听会把真实参数提交到当前插件，声音来自当前的播放或乐器演奏；“返回原音”仅在参数仍等于本次载入状态时恢复，防止覆盖试听后手动修改。关闭浏览器保留当前声音，界面对此有明确提示。

另存当前声音进入用户库，支持名称、类别、作者、标签、说明和原厂来源 ID。原来的 `.vpreset` v1 文件继续有效：新增字段均带 serde 默认值。原厂条目不能被更新或删除；用户预设删除仍移到原有回收目录。FabFilter 文件仍经过原有映射报告，不把部分可映射参数宣称为完整原厂音色兼容。

## 验收与边界

验收在隔离的 Xvfb / Openbox / Mesa 环境进行。截图捕获整个 Xvfb 根窗口，避免 Vulkan 窗口 backing pixmap 陈旧问题。使用实际插件宿主、参数描述符和 PCM；不使用网页 mockup 代替原生窗口。

本次比较证明的是信息层级和操作改进，不能证明不同 DSP 实现之间的逐样本等价，也不能把软件模拟输出验收替代真实硬件、MIDI 设备、多显示器 HiDPI 或各平台窗口管理器验证。可复现的原生截图、兼容回归与具体测试结果随本次 evidence 记录提供。
