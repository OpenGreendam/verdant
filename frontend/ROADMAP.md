# 前端路线图

本文件记录桌面与共享服务的实现边界。使用见 [verdant(1)](README.md)，工作安排见[开发计划](../DEV_PLAN.md)，待验收项见 [TODO](../TODO.md)。

## 当前实现

| 范围 | 已有入口与语义 |
| --- | --- |
| 工程 | `.verp`、显式旧格式导入、创建版本确认、事务、历史及恢复日志。 |
| 编辑 | 多轨卷帘、音符／歌词／读音、分段语言、表达、自动化、音频素材和 MIDI 输入。 |
| 格式与声音 | 七格式交换、WAV 导出、Rust worker、预检、取消、内容缓存和制品校验。 |
| 声库 | 安装并校验 `verdant-voice` 声库包，原版声库通过双摘要验证解锁。 |
| 效果 | 播放／导出共用语义，进程外插入、参数／状态、自动化、缺失插件保留和独占离线实例。 |
| 界面 | Proto UI 卷帘投影与手势状态转换、GPUI 窗口、菜单、快捷键、浅／深色和安静 Pride 配色。 |

按 CLI／DSH 验收矩阵检查同一工程的领域内容、计划、PCM 和交付。平台结果单独记载。[CLI／DSH](../spec/CLI-DSH.md)

## 完成条件

桌面和 CLI 使用相同工程事务、有效参数、时间线、调度与混音。用同一工程比较诊断、计划、缓存身份及最终 PCM；设备、窗口和宿主差异分别记录。

Linux 已有本地模型离线运行记录；Windows x64 和 Apple Silicon 的打包实现仍需对应原生构建、安装、声库、真实声音及回滚结果。IME、读屏、物理触摸、音频设备恢复和插件原生窗口的逐项义务见[平台验收](docs/PLATFORM-ACCEPTANCE.md)。

语言、音域及音色的接受程度使用独立输入、客观测量和试听，见[合成验证](../SYNTHESIS-FIDELITY.md)。历史运行不能代替当前归档验收；发行以 [RELEASE.md](../RELEASE.md) 为准。
